Delete this folder once you have your own presentations

Everything visual lives in this folder: styles.css and an inline SVG favicon.

How a presentation works

  • One folder under presentations/ with an index.html.
  • reveal.js and plugins come from a pinned CDN — nothing to install.
  • CSS, fonts, and images stay inside the folder, so every presentation can look different.
  • task manifest picks the folder up for the landing page.

Two columns

Online

GitHub pages serves the repository as-is. Push to your published branch (typically `main`) and the presentation is live.

Offline

task bundle inlines every asset into a single HTML file under dist/.
